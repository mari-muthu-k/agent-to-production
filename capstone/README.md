# Capstone: Research Paper Summarizer

The final app built across the four workshop days.

The user uploads a research paper (PDF). The agent:

1. **Parses** the PDF into text.
2. **Indexes** it with embeddings and vector search (RAG).
3. **Explains** it in simple terms, answering follow-up questions.
4. **Remembers** the conversation so follow-ups build on earlier answers.

It ships with guardrails, logging, and a simple web UI.
