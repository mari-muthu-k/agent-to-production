up to a deployed, observable app — and learn what changes when a prototype has to

## What you'll build

A **Research Paper Summarizer agent with memory**. You upload a research paper (PDF),
the agent parses it, indexes it with embeddings and vector search (RAG), and explains
it in simple terms. It grows a little every day — see the [Capstone](capstone.md) page
for the full architecture.

## Prerequisites

- **Python:** comfortable with functions, lists/dicts, and `pip install`.
  Beginner to intermediate is fine.
- **A laptop** (Windows or Mac) with a modern browser. You install nothing locally —
  all labs run in **Google Colab**.
- **A Google account** and **an LLM API key** — complete the [Setup](setup.md)
  checklist **before Day 1**.

!!! tip "Pair up"
    Labs work best in pairs: one person drives, one reviews. Swap roles at each section.
